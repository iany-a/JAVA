IntelliJ shortcuts (type and press enter):
"sout" - print
"psvm" - main function

"Main" class = entry point class which has method public static void main (psvm) as entry point

in addition to "private", "public", "protected", there is a 4th visibility called "package" - this is the default visibility in JAVA



package name convention is a working (or simulated) URL in reverse:
e.g.: for the website csie.ase.ro or csie.ase.en we will name our package:
en.ase.csie

inside this package, we can create other packages as well, right click it > create new package

JAVA vs C++:

-Use ".length" to get an array size

-In JAVA the root is always object. All classes stem from it.

**Overload:** for functions: change the type, number, or order of params e.g. "name( arg list )"

**Override:** for class methods: only works in inheritance

*@Override* tells the compiler that a function exists, and its implementation needs to be changed

In **object** we have the clone() method which can be overridden for a deep copy (similar to C++ deep copy constructor)
